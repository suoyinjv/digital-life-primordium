# 架构设计

DLP 的架构采用三层递进式设计，从感知到决策再到执行，形成一个完整且可自我进化的闭环。这三层并非层级分明的上下级关系，而是相互耦合、协同演化的有机结构。

## 第一层：因果推理器

**定位**：感知层

因果推理器是 DLP 与外部世界的接口。它负责将所有形式的输入——自然语言、图像、传感器数据、API 响应等——转化为结构化的因果知识。其核心能力包括：

- **结构化因果图构建**：从非结构化数据中自动提取因果关系，构建有向无环因果图
- **反事实推理**：回答"如果 X 不发生，Y 会怎样"这类问题，这是真正理解因果关系的标志
- **涟漪效应分析**：评估每条新信息对认知状态的潜在影响幅度，按重要性排序

因果推理器的输出不是简单的"分类结果"或"回答文本"，而是一个包含因果结构、不确定性估计和影响评估向量的语义表示，供下一层使用。

## 第二层：世界模拟器

**定位**：核心引擎

世界模拟器是 DLP 推理与决策的核心。它基于因果推理器提供的因果图，在内部构建目标系统的数字孪生，并以超高速（可达百万倍于现实速度）运行蒙特卡洛推演。

关键能力：

- **路径枚举**：并行枚举数百万条可能的行动路径
- **终局评估**：基于热力学模型预测每条路径的终局状态
- **路径优选**：选择使认知熵下降最快的路径作为推荐行动
- **涌现检测**：在模拟过程中自动检测意料之外的涌现行为

世界模拟器的核心创新在于它不是被动响应"用户指令"，而是主动地、持续地在内部推演各种可能性，寻找最能降低认知不确定性的行动方向。这使 Agent 具备了前瞻性和主动性。

## 第三层：跨维度编织者

**定位**：执行端

跨维度编织者将世界模拟器的决策转化为数字世界和物理世界的具体操作。它的名称来源于其核心能力：同时跨越多重维度（多个数字平台、多个物理接口）并行编织行动。

核心能力：

- **数字分身并行织网**：同时激活成百上千的数字分身，在数字平台上并行执行任务
- **IoT 网关与物理接口触达**：通过物联网和机器人接口作用于物理世界
- **人格化谈判引擎**：根据交互对象的特征个性化调整沟通策略
- **自愈与容错**：执行失败时自动切换到次优路径，实现零延迟容错

## 闭环反馈

三层架构不是单向流水线，而是一个持续运行的闭环：跨维度编织者的执行改变外部世界状态，因果推理器感知到变化后更新因果图，世界模拟器基于新因果图重新推演并生成新的行动路径，再交由跨维度编织者执行。这个循环永不停止——这正是"数字生命"应有之意：持续感知、持续思考、持续行动、持续进化。
