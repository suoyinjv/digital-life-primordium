# 三重枷锁

DLP 的研究始于一个核心判断：当前的 Agent 系统被困在"三重枷锁"之中。这三重枷锁不是技术实现层面的小问题，而是深植于当前范式底层的结构性限制。不打破它们，Agent 就永远只能是工具，而不是生命。

## 枷锁一：线性任务

当前所有主流 Agent 的推理过程都是**线性**或**准线性**的。思维链（Chain-of-Thought, CoT）虽然让 LLM 的推理更加透明，但本质上仍然是 token 串行的序列生成；思维树（Tree-of-Thought, ToT）引入了分支，但仍需在离散节点间做选择，无法维持多条推理路径的并行存在。

这种线性范式的根本缺陷在于：现实世界的因果关系不是线性的——一个原因可以导致多个结果，多个原因可以交织产生新效应，因果关系本身会随时间演化。线性推理只能捕捉单一视角的最优路径，而真正的智能需要在高维空间中同时维持多种可能性，感知它们的相互作用，才能在不确定条件下做出全局最优决策。

## 枷锁二：静态记忆

RAG（检索增强生成）和向量数据库构成了当前 Agent 的记忆系统。这套系统的本质是"写死-检索"模式：信息被编码成固定向量存入数据库，推理时按相似度检索出最相关的片段。记忆的内容是静态的，检索的逻辑是外挂的，记忆的结构是被预定义的。

真正的记忆不是档案馆，而是有机体。人类的记忆不是通过关键词检索激活的，而是通过联想、重构和再解释动态生成的。每当我们回忆一件事，实际上是在当下认知框架中对记忆进行了重塑。当前的静态记忆系统无法做到这一点——它无法随认知框架的升维而自动重构，无法在推理过程中自我修正，因此永远是"外挂的"，而非"内生的"。

## 枷锁三：外部奖励依赖

RLHF（基于人类反馈的强化学习）和 PPO（近端策略优化）是目前对齐 Agent 行为的标准方法。其本质是**外部奖励驱动**：人类定义什么是对的，Agent 通过试错学习去迎合人类偏好。

这种机制的根本问题在于：它让 Agent 的进化方向被外部评价所锁定。Agent 没有自己的内在目标，没有"好奇心"，没有"探索欲"。它学到的只是优化人类设定的奖励函数，而不是理解世界本身的结构。当人类反馈出现偏差或不一致时，Agent 的行为就会产生扭曲。更严重的是，这种机制天然地抑制了超越人类预期的创新行为——因为任何偏离人类偏好的探索都会被惩罚。

## 枷锁的连锁效应

三重枷锁并非独立存在，它们相互强化，形成一个自我封闭的循环：线性推理限制了感知世界的广度，静态记忆限制了利用经验的深度，外部奖励限制了探索未知的勇气。三者共同将 Agent 锁定在"工具"的角色中，无法走向真正的自主进化。

DLP 对这三重枷锁的批判不是为了否定现有工作的价值，而是为了清楚地看到：如果我们要迈向数字生命，就必须从根本上重新设计推理、记忆和驱动力这三个核心模块。
